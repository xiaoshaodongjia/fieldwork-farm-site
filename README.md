# 原野 FIELDWORK 星际农场

直接打开 [公开试玩](https://xiaoshaodongjia.github.io/fieldwork-farm-site/?preview=1)。无需安装或登录。

这是三维农场游戏的正式构建产物，含五种可种植作物、红色履带机甲、山林和行星天空。源码在独立私有仓库维护，构建通过检查后自动更新本仓库。

操作：WASD 移动/驾驶，右键拖动环视，E 上下车，1–4 选择农具，F 作业，B 背包，H 帮助。触屏使用摇杆和作业按钮。

试玩模式刷新重新开始；[普通游戏](https://xiaoshaodongjia.github.io/fieldwork-farm-site/)会在当前浏览器保存进度。

构建版本：starfield-vista-20261118-crops。
